## Quiénes somos

El **Instituto de Evaluación Tecnológica en Salud (IETS)** es la entidad de Colombia encargada de evaluar tecnologías en salud y de producir evidencia para la toma de decisiones en el sistema de salud: evaluaciones de tecnologías, guías de práctica clínica, revisiones sistemáticas, evaluaciones económicas y análisis de impacto presupuestal, entre otros productos.

## Sobre esta organización

En este espacio el IETS aloja las herramientas y el software que desarrolla con dos propósitos: **fortalecer la gestión interna del Instituto** y **apoyar las investigaciones, estudios y demás actividades misionales** que adelanta.

Se trata de desarrollos propios, pensados para las necesidades del Instituto y de su trabajo con el sistema de salud colombiano.
